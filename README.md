# Лабораторна робота №1 — перший веб-проєкт

Базова веб-сторінка (HTML5, CSS3, JavaScript) і локальний сервер на Node.js.

## Запуск

```
npm start
```

Сторінка: http://localhost:8080, REST-ендпоінт: http://localhost:8080/api/stack

## Публікація

Сторінка лежить у папці `docs/` і опублікована через GitHub Pages:
https://vladnafta.github.io/web-lab1/
